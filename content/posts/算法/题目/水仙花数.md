# 水仙花数

## 问题

三位数的水仙花数是指一个三位数的每个数字的立方和等于该数本身。求所有三位水仙花数。

## 程序

```python
for num in range(100, 1000):
    a = num // 100      # 百位
    b = (num // 10) % 10 # 十位
    c = num % 10         # 个位
    if a**3 + b**3 + c**3 == num:
        print(num)
```

## 思想

穷举所有可能并打印合适的数。
